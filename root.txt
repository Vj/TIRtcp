3. Technical Upgrades & Real-World Thick-Client ChecksA. Static, Binary & Supply-Chain AccuracyArchitecture-Aware PE Hardening: Checks DYNAMIC_BASE (ASLR), HIGH_ENTROPY_VA (64-bit ASLR), NX_COMPAT (DEP), and GUARD_CF (CFG). Enforces SafeSEH (IMAGE_DLLCHARACTERISTICS_NO_SEH / Load Config SEHandlerTable) strictly on x86 (32-bit) PE binaries, avoiding false positives on x64 binaries where exception handling is table-based.Full Code Signing Verification: Wraps signtool verify /pa /all (Windows) or osslsigncode verify (Linux/macOS) to check not only signature presence, but certificate chain trust, RFC 3161 timestamp validity, and CRL/OCSP revocation status.Hybrid SCA (SBOM + Native Fingerprinting): Generates a CycloneDX/SPDX SBOM via Syft and scans managed packages (JAR, NuGet, npm) with Trivy/Grype, supplemented by regex/binary string version extraction for statically or dynamically linked native libraries (OpenSSL, libcurl, zlib, SQLite).Deep Electron Auditing: Unpacks app.asar and inspects BrowserWindow preferences (nodeIntegration, contextIsolation, sandbox, webSecurity), <webview> tag usage, custom protocol registration (protocol.registerFileProtocol), Electron Fuses (RunAsNode, EnableCookieEncryption, OnlyLoadAppFromAsar), and bundled Chromium/Electron EOL versions.B. Host, Installer, Update & Database ChecksRuntime-Informed DLL Hijacking: Combines static Import Address Table (IAT) checks with a Procmon CSV/XML log parser (Result == "NAME NOT FOUND" where Path resolves to a directory writable by Users or Authenticated Users).Direct Database Connection & Credential Audit: Scans config files (.config, .ini, .properties, .yaml), decompiled resources, and PCAP traffic (TDS/MSSQL, TNS/Oracle, MySQL, PostgreSQL wire protocols) for thick clients connecting directly to backend databases with embedded credentials.Auto-Update Security: Inspects updater configs and binaries for http:// update endpoints, missing cryptographic signature verification on downloaded installers/patches, and user-writable staging directories.Installer, Service & Task Misconfigurations: Audits MSI packages (Custom Actions executing without impersonation/rollback protection, writable temp folders during install), Windows Services (binPath unquoted or writable), and Scheduled Tasks running under NT AUTHORITY\SYSTEM.Debug Artifacts & PII-Leaking Logs: Flags shipped .pdb symbol files, DEBUG compilation flags, and local .log files containing bearer tokens, session IDs, passwords, or PII (directly supporting DPDP safeguard reviews).Expanded IPC & Handler Audit: Evaluates ACLs on Windows Named Pipes, COM/DCOM AppID launch/access permissions, local RPC endpoints, and registered custom URI schemes (myapp://) susceptible to argument injection.C. Gated Runtime & Manual Playbook CoverageGated Post-Logout Memory Inspection (--authorized): Requires both --authorized and --engagement-id (recorded in the HTML report audit banner). Captures process memory strings before and after logout; flags lingering credentials as Evidence of Retention with a Low/Medium/High confidence rating (accounting for unallocated heap artifacts) rather than an automatic Fail.Tool-Specific Manual Playbooks (Manual Required): When automated static/host checks detect indicators of client-side controls or custom protocols, TIRtcp attaches targeted manual verification cards:dnSpy / ILSpy: Inspecting and patching client-side boolean authorization or license checks in .NET assemblies.Frida: Hooking custom TLS certificate pinning routines or native crypto functions at runtime.API Monitor: Tracing LoadLibraryW, CryptProtectData, and CreateProcessW parameters live.Procmon: Capturing boot/runtime NAME NOT FOUND DLL and registry lookups.Wireshark / Burp Invisible Proxy: Replaying non-HTTP TCP frames and testing server-side state validation.4. Revised 4-Phase Implementation RoadmapPhase 1 — MVP (Offline Core & Static/Host Essentials):Build schema.py (canonical JSON/SARIF/HTML model), compliance_map.yaml (PCI DSS v4.0.1, CWE/ASVS, CERT-In, conditional RBI, DPDP), binary_hardening.py (with x86-only SafeSEH), signature_audit.py, secrets_db_audit.py (including debug artifacts & log PII checks), sca_fingerprint.py, basic filesystem ACL checks, and the HTML report renderer.Phase 2 — Network & Protocol Layer (Cross-Platform):Build tls_inspector.py (non-HTTP TLS/pinning checks) and pcap_analyzer.py (cleartext TCP/UDP, direct DB wire-protocol detection, insecure auto-update traffic). Delivers high-impact findings without requiring target-host installation.Phase 3 — Windows Collector, Managed Runtimes & IPC:Build the standalone Windows collector/ (host_evidence.json bundle), dll_hijack_parser.py (IAT + Procmon CSV parser), electron_unpack.py (including Fuses), installer/service/task checks, and ipc_uri_audit.py (Named Pipes, COM/DCOM, custom URIs).Phase 4 — Gated Runtime & Memory Hygiene:Implement auth_gate.py (--authorized + --engagement-id) and memory_retention.py with confidence-scored Evidence of Retention reporting.
